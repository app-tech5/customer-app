Overview (Presentation)

Good Food Pro - Customer App is the mobile storefront of your food delivery business. It turns restaurant browsing and ordering into a clear, smooth, and user-friendly journey.

As the customer-facing part of the Good Food Pro ecosystem, it is designed to help users go from "I am hungry" to "Order confirmed" with minimal friction and maximum clarity.

Customer App Presentation

This app is made for everyday users, not only advanced users. The interface is simple, visual, and action-oriented so even first-time customers can order with confidence.

Customers can sign in, discover nearby restaurants, explore menu items, add products to the cart, and complete checkout in a smooth, guided flow.

Beyond ordering, the app includes practical account features such as address management, language preferences, payment options, and order follow-up to improve retention and trust.

Main Function

The core mission is simple: let users place food orders from mobile, from item discovery to final confirmation.

In real usage, customers can search restaurants, filter by preferences, review menu details, customize quantities, and checkout in a few steps.

After checkout, the app continues the experience with order status visibility, reducing uncertainty and improving satisfaction during delivery.

Supported Platforms

  • Android
  • iOS

A single shared codebase powers both platforms, which helps maintain consistent user experience and visual quality across devices.

This approach also lowers maintenance cost and speeds up feature delivery, updates, and bug fixes for product teams.

In customer-app, the stack is centered on the JavaScript ecosystem with React Native and Expo for mobile delivery on Android and iOS.

The architecture combines robust mobile UI foundations (navigation + state management) with REST API integration for production-ready ordering workflows.

Note: the backend is sold separately. This customer app connects to a compatible Good Food Pro backend API when available.

Global Prerequisites

  • Node.js LTS (>= 16)
  • npm or yarn
  • Expo CLI / Expo tooling
  • Android Studio (Android) or Xcode (iOS)
  • A running and reachable backend API (sold separately)

These are the only essentials you need to install, run, and test the app successfully. If you are new to mobile projects, this setup is still beginner-friendly with clear tools.

  • Use a stable Node.js LTS version for smoother installation.
  • Make sure your phone/simulator can reach the backend API URL.
  • Keep Android/iOS tools updated for predictable builds and tests.
